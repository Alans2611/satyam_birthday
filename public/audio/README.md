# Background Music for Satyam's Birthday Website

To add romantic background music to this website:

1. Choose your favorite romantic song or instrumental track (e.g. piano, acoustic guitar, or a song that is meaningful to both of you).
2. Save or convert it as an MP3 file named:
   `romantic.mp3`
3. Place `romantic.mp3` directly into this folder:
   `public/audio/romantic.mp3`

### Notes
- The website is designed to never autoplay audio until Satyam interacts with the player.
- If no audio file is provided, the music control gracefully hides itself and will not cause any errors.
- Recommended format: MP3, 128kbps - 192kbps (small file size for quick loading on mobile).
